## 2. 应用说明（描述，直接粘贴）

---

**屏幕熄了，活照干。** QuietScreen（屏息）是给 Windows 笔记本用的息屏远控工具。

让系统常驻一块 Parsec 虚拟显示器。需要离开时，一键把内置屏幕从显示拓扑里真正摘掉（硬件级断电，不是黑色遮罩软件）；任务继续运行，远程控制看到的是虚拟屏桌面。回来时一个热键点亮内屏，秒级切换。

**核心特性**

- 🔌 **真熄屏省电**：内屏从拓扑级断电，不靠遮罩、不靠调暗
- ⚡ **秒级切换**：虚拟屏常驻保活（驱动心跳），切换只是显示拓扑变化
- ⌨️ **全局热键**：Ctrl+Alt+Esc 息屏远控 / Ctrl+Esc 点亮内屏（远控客户端注入的按键同样有效）
- 🛡️ **守护巡检**：虚拟屏掉线自动恢复，远控代理（如向日葵）掉线自动拉起（可选，默认关闭）
- 🖥️ **分辨率自动校正**：夜间模式固定虚拟屏 2560x1600@60 / 150% 缩放，远程桌面不糊不偏
- ⏰ **每日定时关机**：系统级倒计时，触发前可一键取消
- 🌙 **防睡眠**：运行期间系统不会自动睡眠/休眠/熄屏，退出即恢复系统默认
- 🔒 **完全离线**：不联网、不收集、不上传任何数据，没有账号和遥测

**首次使用**

1. 启动后若提示驱动未安装，点"安装虚拟屏驱动"并确认 UAC（内置 Parsec 官方驱动包 v0.45，驱动版权归 Parsec Cloud Inc.，约 10-20 秒装完）
2. 装完驱动后在 Parsec 驱动设置中开启 **Keep Screen On（保持屏幕常亮）**，否则虚拟屏会被系统收回（应用"设置"页有此说明）
3. 离开前按 Ctrl+Alt+Esc；回来按 Ctrl+Esc
4. 需要代理守护时在"守护"页开启并填入你远控程序的路径（默认关闭）

注意：本程序所有切换均由你手动触发，不会拦截键鼠，也没有"闲置自动息屏"。

**Description:**

> **Screen off. Work goes on.**
>
> QuietScreen is a screen-off remote-control utility for Windows laptops. It keeps a Parsec virtual display alive in the background, so when you need to leave, one keystroke removes the built-in panel from the display topology (a true hardware power-off — not a black overlay). Your tasks keep running, and remote-control sessions show the virtual display's desktop. One more keystroke brings the internal screen back, in about a second.
>
> **Highlights**
>
> - 🔌 True screen power-off — topology-level, not a dimming overlay
> - ⚡ Second-fast switching — the virtual display stays alive via driver heartbeat
> - ⌨️ Global hotkeys — Ctrl+Alt+Esc to screen off, Ctrl+Esc to wake (works with injected remote keys)
> - 🛡️ Guardian watch — auto-restores the virtual display, auto-restarts your remote agent (optional, off by default)
> - 🖥️ Auto resolution correction — locks the virtual display at 2560x1600@60 with 150% scaling
> - ⏰ Daily scheduled shutdown — system-level countdown, cancellable
> - 🌙 Anti-sleep — no auto sleep/hibernate/display-off while running
> - 🔒 Fully offline — no network, no telemetry, no accounts
>
> **First run:** if the driver is missing, click "Install display driver" and confirm the UAC prompt (bundled official Parsec driver v0.45, copyright Parsec Cloud Inc.). Then enable "Keep Screen On" in the Parsec driver settings, or the virtual display will be reclaimed by Windows. Press Ctrl+Alt+Esc before you leave; Ctrl+Esc when you're back.
>
> Note: every switch is manually triggered. The app never intercepts your keyboard/mouse and never auto-screens-off on idle.
