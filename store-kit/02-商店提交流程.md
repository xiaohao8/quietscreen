# QuietScreen 微软商店提交流程（完整清单）

> 全流程约 1~3 小时操作 + 1~7 天审核等待。所有需要你自己决定/填写的地方都用 🔶 标出。

## 第 0 步 · 前置条件

- [ ] 微软开发者账户：https://developer.microsoft.com/dashboard → 注册 Windows 应用计划
  - 个人账户 **$19**（一次性），公司账户 $99。个人账户即可上架。
  - 注册需要完成身份验证（邮箱/手机/付款）。
- [ ] 🔶 决定发布者显示名（Partner Center 里显示的名字，如你的昵称/工作室名）
- [x] 对外联系邮箱：`3543601929@qq.com`（商店页"支持联系方式"必填，隐私政策里也用它）
- [ ] 🔶 决定商店名称：建议直接保留 **"QuietScreen 屏息"**（与包内 DisplayName 一致）

## 第 1 步 · 保留应用名称

1. Partner Center → **应用和游戏 → 创建新应用**
2. 输入名称（如 `QuietScreen 屏息`）→ 系统检查唯一性并**保留**
3. 进入应用后 → **应用管理 → 应用标识**，记下三个值：
   - **Package/Identity Name**（如 `12345Author.QuietScreen`）
   - **Package/Identity Publisher**（如 `CN=AB12CD34-EF56-...`）
   - **Package/Identity Version** 规则建议：`1.0.0.0` 起，后续每次提交递增

## 第 2 步 · 生成上架包（在你自己的构建机上执行）

```powershell
# 在仓库根目录:
powershell -File packaging/build-store.ps1 `
    -IdentityName "第1步拿到的IdentityName" `
    -Publisher "CN=第1步拿到的Publisher" `
    -Version "1.0.0.0"
```

产物：
- `packaging/out/QuietScreen_1.0.0.0_x64.msixupload` ← **上传商店用这个**
- （同目录的 .msix 是自签测试包，可本机装来验证，别传上去）

注意：
- 构建机需要 .NET 10 SDK + Windows SDK（makeappx/signtool，脚本自动找最新版本目录）。
- 商店会重新签名，上传包不必用正式证书。
- 提交前务必用测试包在自己机器上完整走一遍：安装 → 首次启动 → 一键息屏 → Ctrl+Esc 恢复 → 定时关机取消。

## 第 4 步 · 属性 / 分级 / 定价

- **类别**：实用工具（Utilities）；子类别：工具（Tools）
- **年龄分级问卷**：全部答"否"（无暴力/赌博/成人/在线交互/不收集个人信息）→ 得 IARC 3+/PEGI 3/ESRB E
- **定价**：免费
- **市场**：全部 241 个市场（默认即可）
- **发布日期**：认证通过后立即发布（或手动）

## 第 5 步 · 认证备注（提交最后一页 "Notes for certification"）

把《05-认证审核备注.md》全文粘贴进去。**这一步对这个应用尤其重要**：审核员如果不提前知道"会创建虚拟显示器、会熄灭内屏、装驱动要弹 UAC"，很容易被判"异常行为"拒审。

## 第 6 步 · 内嵌驱动安装包的风险预案（重要）

`runFullTrust` 应用启动外部安装器技术上可行，但商店审核对内核驱动安装从严，且 Parsec 驱动二进制的再分发授权未明。两个方案：

- **方案 A（先试）**：按当前代码提交（内嵌 parsec-vdd-0.45.0.0.exe），在商店描述里明确披露"首次使用需通过 UAC 安装 Parsec 虚拟屏驱动（驱动版权归 Parsec Cloud Inc.）"，审核备注里说明来源与用途。若通过，成本最低。
- **方案 B（被拒后最小改动）**：去掉内嵌安装包，把主页"一键安装"按钮改为打开 Parsec 官方驱动发布页（`https://github.com/nomi-san/parsec-vdd/releases`，代码里 `SettingsView.cs:104-115` 已有同款跳转写法），应用本身只做状态检测。改动面 ≈ 10 行 + 移除一个资源文件，不动任何核心逻辑。

## 第 7 步 · 提交与跟踪

1. Partner Center → **提交审核**
2. 审核一般 1~3 个工作日，桌面应用偶尔 5~7 天
3. 被拒时看"认证报告"里的错误码：
   - `10.2.x`（独立安装/引导安装第三方软件）→ 走方案 B
   - `MSIX 验证错误` → 检查身份参数是否与 Partner Center 完全一致
   - `崩溃/挂起` → 附上 `%LOCALAPPDATA%\QuietScreen\logs\quietscreen.log` 复现说明
4. 通过后商店页在几小时内全球生效
