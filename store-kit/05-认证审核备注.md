# Notes for certification（认证备注，提交时整段粘贴）

> 放在 Partner Center 提交流程最后的 "Notes for certification" 输入框。中文为主、附英文摘要，方便不同地区审核员。

---

本应用（QuietScreen 屏息）是一款本地运行的 Windows 桌面工具，用于笔记本息屏远控。为避免误判，请审核时注意以下行为都是**设计的核心功能**，不是异常：

1. **显示拓扑变化与短暂黑屏**
   应用会通过已安装的 Parsec 虚拟屏驱动（Parsec Virtual Display Adapter）创建/移除虚拟显示器。创建、移除或切换显示拓扑时，Windows 会短暂黑屏 0.5~3 秒——这是操作系统对显示器插拔的正常反应，与应用崩溃无关。

2. **"一键息屏远控"会真正熄灭内置屏幕**
   点击主页"一键息屏远控"（或按 Ctrl+Alt+Esc）后，内置屏幕会从显示拓扑中断电（画面转由虚拟屏承载）。**恢复方法：按 Ctrl+Esc，或点托盘图标菜单"恢复内屏"。** 测试时如需找回画面，用 Ctrl+Esc 即可，无需重启。

3. **安装驱动会弹出 UAC 并需要管理员确认**
   首次使用时，应用内"安装虚拟屏驱动"按钮会提取内置的 Parsec 官方驱动安装包（parsec-vdd-0.45.0.0.exe，来源：Parsec Cloud Inc. 官方发布，与开源项目 nomi-san/parsec-vdd 使用同一安装流程），经用户在 UAC 对话框确认后静默安装。安装约 10-20 秒，无需重启。若测试环境不允许安装驱动，应用的其他功能（定时关机、设置、日志等）仍可正常审核。

4. **runFullTrust 的用途**
   仅用于：SetDisplayConfig/ChangeDisplaySettingsEx 控制显示拓扑、与驱动设备句柄通信（IOCTL）、SetThreadExecutionState 防睡眠、调用系统 shutdown.exe 实现可取消的定时关机。无网络通信代码。

5. **完全离线**
   应用不联网、不收集数据、无遥测；配置与日志仅写入本地 %LOCALAPPDATA%\QuietScreen。隐私政策 URL 见商店列表。

6. **测试提示**
   - 应用启动后常驻托盘，关闭主窗口 = 最小化到托盘（守护继续运行），从托盘右键可退出。
   - 建议测试顺序：启动 → 查看主页驱动状态 → 安装驱动（UAC）→ 在 Parsec 驱动设置开启 Keep Screen On（否则虚拟屏会被系统收回，应用"设置"页有说明）→ 一键息屏远控 → Ctrl+Esc 恢复 → 定时关机页安排 30 秒关机 → 立即取消。
   - 虚拟机测试时驱动安装/显示切换行为可能与物理机不同，属正常。

**English summary:** This is an offline WPF utility for laptop screen-off remote control. Intended behaviors that may look unusual: (a) it creates/removes a Parsec virtual display, which briefly blanks the screen as Windows re-applies display topology; (b) "One-click screen-off" turns OFF the internal panel by design — press Ctrl+Esc to restore; (c) the in-app driver installer launches the official Parsec driver setup (parsec-vdd-0.45.0.0.exe) elevated via UAC after explicit user confirmation; (d) runFullTrust is used solely for display topology control, driver IOCTLs, power state, and cancellable shutdown scheduling. No network code, no telemetry.
