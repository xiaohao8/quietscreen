Privacy Policy

隐私政策

适用产品：QuietScreen 屏息（Windows 桌面应用） · 发布者：付志豪 · 最后更新：2026 年 11 月 9 日

本页正式地址：https://quiet.202271.xyz/privacy.html

一句话版本：QuietScreen 是一款完全离线的本地桌面工具，不收集、不上传任何个人数据。没有账号、没有遥测、没有统计与崩溃上报。

1 · 我们收集什么

不收集任何数据。具体而言，本应用：

  • 不向任何服务器发送用户数据，不含遥测、使用统计、崩溃上报或广告 SDK；
  • 没有账号系统，不需要注册、登录或绑定手机号、邮箱；
  • 不读取浏览器历史、通讯录、位置、照片、剪贴板等个人信息；
  • 不含任何需要联网才能使用的功能。

应用内少数外部链接（例如驱动项目主页、灯效工具网站）只会在你主动点击后由系统默认浏览器打开，应用本身不发起该请求，也不向这些站点传递任何应用数据。

2 · 本地数据

以下数据仅保存在你自己的电脑上，永远不会自动离开你的设备：

  • 配置文件 %LOCALAPPDATA%\QuietScreen\config.json —— 你在应用内的偏好设置，例如巡检间隔、热键开关、你自行填写的远控程序路径与端口；
  • 日志文件 %LOCALAPPDATA%\QuietScreen\logs\quietscreen.log —— 排错用运行记录，可能包含显示器名称、驱动版本、你自行填写的代理程序路径；不包含账号、密码或网络数据。

你可以随时手动删除上述文件，应用会以默认配置重建。若开启了可选的「远控代理守护」，应用只会在本机回环地址（127.0.0.1）探测你指定的端口是否监听，该探测不会离开本机。

3 · 第三方组件

应用使用 Parsec Virtual Display Driver（版权归 Parsec Cloud Inc.）实现虚拟显示器功能。驱动安装包随应用内置，从本地提取，不会联网下载；安装需要你在系统 UAC 对话框中主动确认。我们无法访问、也不处理 Parsec 相关的任何账号或网络服务。

应用还使用了若干开源组件（详见随包分发的 THIRD-PARTY-NOTICES 与 LICENSE 文件），它们仅作为本地代码运行，不引入数据收集行为。

4 · 权限说明

应用声明「完全信任」（runFullTrust）权限，仅用于：控制显示拓扑、与已安装的虚拟屏驱动通信、管理电源状态与定时关机、注册全局热键。上述操作全部在本地完成。

注册全局热键后，Ctrl+Esc 不再打开开始菜单（请改用 Win 键）；这是 Windows 热键机制的行为，不涉及键盘记录或输入内容采集。

5 · 关于本网站

本网站仅提供静态介绍页面与本政策文本：不设置 Cookie、不使用分析或统计脚本、不加载第三方字体与 CDN 资源、不提供表单或留言功能。托管服务商可能按其通用规则记录访问日志（如 IP、User-Agent），这属于托管基础设施行为，不由本应用或本站主动采集，也不用于识别个人。

6 · 联系我们

如有隐私相关问题，请发邮件至 vip@mrds.app，或通过 Microsoft Store 应用页面的「支持联系方式」联系发布者。我们会在合理期限内回复。

7 · 政策变更

如政策发生变化，我们将在本页面更新内容并修改页首的「最后更新」日期。应用行为的实质性变化也会同步更新商店列表说明。

Summary (English)

QuietScreen is a fully offline Windows desktop utility. It collects no personal data, has no accounts, no telemetry, no analytics and no crash reporting. Configuration and diagnostic logs are stored only on the local device under %LOCALAPPDATA%\QuietScreen and can be deleted by the user at any time. The bundled Parsec Virtual Display Driver is installed from local files only after explicit user confirmation via UAC. This website is a static page with no cookies and no third-party scripts. Privacy questions: vip@mrds.app.
