# Quiet · 屏息 —— 使用说明

**屏幕熄了，活照干。** 给 Windows 笔记本用的息屏远控工具。

## 它做什么

让 Windows 笔记本常驻一块虚拟显示器，在需要离开时把内置屏幕从显示拓扑里摘掉（真断电，不是黑色遮罩），任务继续运行，远程控制看到的是虚拟屏桌面。

| | **本机模式**（默认） | **夜间远控模式** |
| --- | --- | --- |
| 内屏 | 点亮，正常使用 | 拓扑级断电（真熄屏） |
| 虚拟屏 | 后台保活，不占桌面 | 激活为主屏，远程画面走它 |
| 键盘灯 | 恢复亮度 | 尝试熄灭 |
| 远控代理守护 | 可选，默认关闭 | 可选，默认关闭 |

- 进入夜间：按 `Ctrl+Alt+Esc`，或点主页 / 托盘的“一键息屏远控”
- 回到本机：按 `Ctrl+Esc`，或点主页 / 托盘的“恢复内屏”
- 切换是纯显示拓扑变化，虚拟屏常驻保活，所以是秒级的

> 本版本**没有**“本机闲置自动息屏”，也**不会**拦截本机键鼠；所有切换都由你手动触发。

## 热键

| 热键 | 作用 |
| --- | --- |
| `Ctrl+Alt+Esc` | 息屏远控（没有虚拟屏时会自动创建） |
| `Ctrl+Esc` | 点亮内屏，回到本机模式 |

注册后 `Ctrl+Esc` 不再打开开始菜单（开始菜单请用 `Win` 键）。

## 首次使用

1. 启动后程序会在后台确保一块虚拟屏存在（约 5 秒，仅首次）。
2. 如果“设置”页显示驱动未安装，点“安装驱动”，按 UAC 提示确认。
3. 需要代理守护的话，在“守护”页开启开关，填入你本机远控程序的 exe 路径和参数（默认关闭）。
4. 离开前按 `Ctrl+Alt+Esc` 息屏；回来按 `Ctrl+Esc` 点亮。

## 驱动

程序内置 Parsec 官方虚拟屏驱动安装包（v0.45）。安装由你手动点击触发，会弹一次 UAC；安装完成后无需重启。

若驱动状态异常，可在“设置”页重新检测或重装。驱动是独立的内核组件，卸载本应用不会自动卸载它。

## 定时关机

“定时关机”页：

- 每日定时：默认 **02:00**，**默认关闭**，需要手动开启
- 临时安排：30 / 60 / 10 分钟后关机
- 取消已安排的关机

倒计时由 Windows 系统接管，程序退出后仍会执行。

## 配置与日志

- 配置：`%LOCALAPPDATA%\QuietScreen\config.json`
- 日志：`%LOCALAPPDATA%\QuietScreen\logs\quietscreen.log`

配置和日志只保存在本机；日志可能包含显示器名称、驱动版本、代理程序路径等排错信息，不包含账号或网络数据。

## 常见问题

**Q: 远程断线了怎么连回来？**
A: 虚拟屏常驻保活；如果配置了代理守护，代理掉线会被拉起。直接重连即可，息屏状态下远程看到的是虚拟屏桌面。

**Q: 想用内屏怎么办？**
A: 按 `Ctrl+Esc`，或点“恢复内屏”。

**Q: 为什么程序启动后外接屏没有变化？**
A: 本机模式不改显示拓扑，只保证虚拟屏在后台保活。只有按 `Ctrl+Alt+Esc` 进入夜间模式时才会切到“仅外接/虚拟屏”。

**Q: 和旧版 VddKeeper.ps1 / ParsecVDisplay 什么关系？**
A: 本程序是它们的替代品（虚拟屏保活 + 守护 + 秒切）。不要同时运行旧脚本；旧版 ParsecVDisplay 可能与本程序抢屏。
