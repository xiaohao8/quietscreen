# Quiet · 屏息 —— 使用说明

**屏幕熄了，活照干。** 宿舍息屏远控工具。

## 它做什么

让 Windows 笔记本常驻一块虚拟显示器，两种模式一键切换：

| | **本机模式**（默认） | **夜间远控模式** |
| --- | --- | --- |
| 内屏 | 点亮正常使用 | 拓扑级断电（真熄屏） |
| 虚拟屏 | 后台保活（不可见） | 激活为主屏，远程画面走它 |
| 防误触 | 解除 | 拦截本机键鼠（远程操作放行） |
| 键盘灯 | 恢复亮度 | 尝试熄灭 |
| 代理守护 | ✅ | ✅ |

- 回到本机：**按住 Ctrl+Esc 1 秒** 或 `Ctrl+Esc` 或托盘"恢复内屏"
- 进入夜间：**Ctrl+Alt+Esc** 或 托盘/主页"一键息屏远控" 或 **本机闲置 30 分钟自动**
- 01:00 定时关机（可选，守护页开关）

## 热键

| 热键 | 作用 |
| --- | --- |
| `Ctrl+Alt+Esc` | 息屏远控（无虚拟屏时会自动创建） |
| `Ctrl+Esc` | 点亮内屏，回到本机模式 |

注意：注册后 Ctrl+Esc 不再打开开始菜单（开始菜单用 Win 键）。

## 首次使用

1. 首次启动会自动创建一个常驻虚拟屏（约 5 秒，仅此一次）
2. 需要远控代理守护的话，在"守护"页填入向日葵 AweSun.exe 路径（默认 49671 端口）
3. 离开电脑前按 `Ctrl+Alt+Esc` 息屏，或直接走人——闲置 30 分钟自动息屏

## 驱动

内置 Parsec 官方虚拟屏驱动安装包（v0.45）。没装驱动的电脑首次使用会引导一键安装。
若驱动状态异常，可在"设置"页重新检测或重装。

## 定时关机

"定时关机"页：
- 每日定时（下拉选时间，到点弹系统倒计时，宽限期内可取消）
- 临时安排（30/60/10 分钟后关机）
- 取消已安排的关机

倒计时由 Windows 系统接管，程序崩溃倒计时依然有效。

## 配置文件

`%LOCALAPPDATA%\QuietScreen\config.json`（设置页可打开所在文件夹）

## 常见问题

**Q: 远程断线了怎么连回来？**
A: 虚拟屏常驻 + 向日葵代理自动拉起，直接重新连接即可；息屏状态下远程看到的是虚拟屏桌面。

**Q: 想用内屏怎么办？**
A: `Ctrl+Esc` 或按住 `Ctrl+Esc` 1 秒（息屏状态下）点亮内屏。

**Q: 和旧版 VddKeeper.ps1 脚本 / ParsecVDisplay 什么关系？**
A: 本程序是它们的完整替代品（虚拟屏保活 + 守护 + 秒切），请勿同时运行旧脚本或 ParsecVDisplay。
